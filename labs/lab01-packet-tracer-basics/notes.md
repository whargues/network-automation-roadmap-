# Lab 01 – Packet Tracer Basics

## Objective
Learn how to navigate Packet Tracer and set up the workspace for future labs.

## Skills Practiced
- Changing CLI text size and font colors in Preferences
- Adding equipment to the diagram (routers, switches, PCs, servers, firewalls, laptop)
- Renaming devices for clarity
- Using "Automatically Choose Connection Type" for cabling
- Faster connections by holding Ctrl and clicking devices
- Navigating the workspace and organizing devices

## Reflection
This lab was focused on learning the Packet Tracer interface rather than networking configs.  
I can now confidently add, rename, and connect devices, and adjust CLI settings for readability.  
This sets the foundation for recreating more complex labs from memory later.
